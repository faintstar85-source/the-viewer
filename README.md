# The Viewer 정

Windows용 PDF·사진 뷰어입니다. 여러 자료의 페이지를 정리하고, PDF의 글자·그림·선을 편집하며, 원본과 수정본을 좌우로 비교할 수 있습니다.

**[다운로드와 버전별 변경사항](https://github.com/faintstar85-source/the-viewer/releases/latest)** · [사용 안내](docs/PROGRAM_GUIDE.md) · [전체 수정 기록](CHANGELOG.md) · [오류 제보와 기능 요청](https://github.com/faintstar85-source/the-viewer/issues) · [개발자 블로그](https://blog.naver.com/faintstar)

## 문서 기준

이 안내의 현재 소스 기준은 **The Viewer v3.13.42**입니다. 실제 공개된 설치 파일과 배포 버전은 [GitHub Releases](https://github.com/faintstar85-source/the-viewer/releases)에서 확인하세요.

일반 사용자는 릴리스에 첨부된 설치 EXE를 사용합니다. 설치 배포본은 Python을 별도로 설치하지 않고 실행할 수 있습니다.

## 코드 수정과 자동 배포

저장소의 `pdf_page_dragger.py`와 `release.json`을 함께 업데이트하면 GitHub Actions가 Windows 설치 파일을 만듭니다. 제작 PC에서 별도 패키징·업로드 프로그램을 실행할 필요가 없습니다.

- 소스·빌드 도구 검사 → Windows 소스·EXE·최종 위치 검사 → 설치 EXE·ZIP 생성 → 첨부파일 크기·SHA-256 확인 순서로 진행합니다.
- `release.json`의 `publish`가 `true`이면 검사 후 공개하고, `false`이면 초안으로 준비합니다. 이미 배포한 버전은 다시 사용하지 않습니다.
- 사용자는 기존 **정 → 업데이트**에서 새 설치 파일을 확인합니다.

[자동 빌드·배포 상태](https://github.com/faintstar85-source/the-viewer/actions/workflows/release.yml) · [제작자 안내](docs/BUILD_AND_GITHUB.md)

## v3.13.42 변경사항

- PDF 편집 글꼴 목록에 현재 쪽 사용 글꼴을 먼저 표시하고, 맑은 고딕을 위쪽에 배치합니다.
- 상단에 문서·연필 모양의 편집 버튼을 추가하고, 편집 상태를 색으로 구분합니다.
- 한글·번역 버튼은 기본으로 숨깁니다. **정 → 번역 / 한글 변환 → 상단 버튼 표시**에서 필요한 버튼을 켭니다.

[이번 버전 수정 내역](releases/RELEASE_NOTES_v3.13.42.md)

## v3.13.40–3.13.41 변경사항

- 내부 페이지 드래그 전에 임시 PDF 사본을 만들던 처리를 생략했습니다.
- 사진 한 장을 직접 열어도 사진이 든 폴더를 기준으로 인접 폴더를 탐색합니다.
- 3.13.41에는 GitHub에서 빌드·검사·배포를 수행하는 자동화를 추가했습니다. 기존 저장소의 아이콘을 유지합니다.

## v3.13.39 변경사항

- The Viewer 창 사이에 PDF 페이지를 드래그할 때 사본 이름 창이 뜨지 않도록 표시 조건을 조정했습니다.
- 드래그 후 사본 이름 변경은 Windows 탐색기·바탕화면으로 확인된 대상에서 복사 동작이 반환되고, 사본 이름 변경 설정이 켜져 있을 때만 진행합니다.
- 외부 복사가 끝나기 전에 임시 PDF를 지우지 않도록 보존하고, 복사본의 크기와 내용을 확인한 뒤 이름을 바꿉니다.
- 복사본을 확인하지 못하면 저장할 폴더를 선택해 다시 저장할 수 있습니다. 같은 이름의 파일을 덮어쓰지 않으며, 파일 잠금으로 이름 변경이 실패하면 재시도합니다.
- 최근 페이지 캐시 한도를 8쪽·64MiB에서 32쪽·256MiB로 늘리고 PDF의 앞뒤 페이지를 미리 읽도록 변경했습니다.
- PDF 미리보기 해상도를 실제 화면 픽셀 크기에 맞추고, 확대 시 필요한 해상도로 다시 읽도록 조정했습니다.

[이번 릴리스 설명](releases/RELEASE_NOTES_v3.13.39.md) · [PDF 읽기 구조](docs/READING_SPEED.md)

## 기존 주요 기능

- Ctrl+F로 PDF 문자를 검색하고, 결과 위치로 이동하거나 검색 전 위치로 돌아갑니다.

- PDF 읽기를 GUI·편집 초기화보다 먼저 시작하고 원본을 직접 표시합니다. 양식 페이지는 기존 경로로 전환합니다. [읽기 구조와 확인 범위](docs/READING_SPEED.md).
- PDF 화면 전달의 PNG 압축·해제를 줄이고, 읽은 화면으로 썸네일을 만듭니다. [읽기 구조](docs/READING_SPEED.md).
- 우클릭 드래그 범위에 일부만 걸친 글자·그림·표선을 선택합니다. 얇은 선에는 화면 기준 약 3px의 선택 여유를 둡니다.
- 여러 얇은 채움 사각형을 한 경로로 묶어 저장한 PDF 표선도 편집 대상으로 읽습니다.
- 글자와 표선을 함께 옮길 때 PDF 재기록의 미세한 좌표 반올림 때문에 선 연결이 끊기는 오류를 수정했습니다.
- Ctrl로 선택을 추가하거나 일부를 해제하고, 다른 쪽에 같은 X/Y 좌표로 복사합니다.
- 1|2 집중모드에서 버튼을 숨겨 그림 표시 공간을 넓힙니다. 오른쪽 그림 맨 오른쪽 위에 마우스를 올리면 해제 화살표가 나오며, Esc로도 해제합니다.
- ZIP·CBZ는 두 장 보기로, PDF·그림은 주 보기와 썸네일로, PY·HTML은 텍스트 편집기로 시작합니다.
- Python 편집기의 함수 선택·교체, 수정 전후 비교와 저장 전 문법 검사를 지원합니다.
- [쪽] 메뉴에서 페이지 번호 생성·삭제, 썸네일 우클릭에서 좌우 90도 회전을 사용합니다.

## 주요 기능

아래 이미지는 기존 기능 설명용 **AI 일러스트**입니다. 실제 프로그램 화면이나 검출 성능을 나타내는 자료는 아닙니다.

### 1. PDF와 사진을 한 화면에서 확인

![PDF와 사진 보기 기능 설명용 AI 일러스트](assets/guide/01_viewer.png)

시작 화면의 **[+]**에 파일을 드롭하거나 더블클릭해 파일을 선택합니다. 썸네일에서 필요한 쪽을 골라 크게 보고, ZIP·CBZ 안의 이미지도 페이지로 읽을 수 있습니다.

TXT·PY·MD 같은 일반 텍스트는 읽기 페이지로 표시하며, 본문을 수정해 텍스트 파일로 저장할 수 있습니다.

[기본 사용 방법](docs/PROGRAM_GUIDE.md) · [지원 형식과 변환](docs/FORMATS_AND_CONVERSION.md)

### 2. 페이지 정리와 PDF 편집

![페이지 정리와 PDF 편집 기능 설명용 AI 일러스트](assets/guide/02_edit.png)

썸네일을 드래그해 순서를 바꾸고 다른 PDF나 사진을 추가합니다. PDF의 글자·그림·선·표 테두리는 **글/그림 편집**에서 선택해 조절합니다.

글상자 안쪽은 글자 입력, 테두리는 이동, 손잡이는 크기 조절에 사용합니다. 여러 개체의 정렬·간격 조절과 다른 페이지에 같은 좌표로 붙여넣기도 지원합니다.

스캔 이미지 안의 문자는 텍스트 개체로 인식하지 않습니다. OCR 편집 기능은 포함되어 있지 않습니다.

[PDF 편집 자세히 보기](docs/PDF_EDITING.md)

### 3. 좌우 듀얼 보기

![좌우 듀얼 보기 기능 설명용 AI 일러스트](assets/guide/03_dual.png)

듀얼 보기에는 두 자료를 비교하는 **A|A 검토 모드**와 같은 작업 목록의 두 쪽을 나란히 읽는 **1|2 두 장 모드**가 있습니다. 모드 버튼을 눌러 전환합니다.

검토 모드에서는 오른쪽에 다른 자료를 열 수 있습니다. 양쪽 클립을 잠그고 동시 이동을 켜면 페이지 이동·확대·스크롤을 함께 조절할 수 있습니다. 오른쪽 보기는 읽기 전용입니다.

[듀얼 보기와 비교 안내](docs/DUAL_VIEW.md)

### 4. 변경이 의심되는 위치 검토

![차이 후보 표시 기능 설명용 AI 일러스트](assets/guide/04_review.png)

차이 비교는 현재 표시 중인 두 쪽을 대조해 확인할 위치를 원형 후보로 표시합니다. 이전·다음 후보로 이동하며 내용을 확인합니다.

정렬이 불확실한 경우 분석을 보류합니다. 후보가 없다는 이유만으로 문서 전체가 동일하다고 확정하지 않습니다.

[차이 후보와 분석 보류](docs/DUAL_VIEW.md#차이-후보-검토)

### 5. 번역과 한글 변환

![PDF 번역과 한글 변환 기능 설명용 AI 일러스트](assets/guide/05_conversion.png)

DeepL API 키를 설정해 PDF를 한국어로 번역하고, PDF의 글·표·그림을 한글 편집용 문서로 변환할 수 있습니다. 결과 저장 후 원본과 결과를 좌우 검토뷰에서 확인합니다.

번역 문서는 DeepL 서비스로 전송되며 API 이용 조건이 적용됩니다. 한글 간편 보기와 변환 결과는 복잡한 서식에서 원본 배치와 차이가 날 수 있습니다.

[번역·한글 변환·인쇄 안내](docs/FORMATS_AND_CONVERSION.md)

### 6. 설치와 프로그램 내부 업데이트

![설치와 업데이트 기능 설명용 AI 일러스트](assets/guide/06_update.png)

설치 EXE를 실행하고, PDF/JPG 기본 앱으로 사용할 경우 Windows 기본 앱 설정에서 The Viewer를 선택합니다. 프로그램의 **정 → 업데이트**에서도 새 버전을 확인할 수 있습니다.

ZIP 배포본은 압축을 풀고 동봉 파일을 함께 유지합니다. 코드 수정과 GitHub 자동 배포는 제작자 안내를 참고하세요.

[설치·업데이트 안내](docs/INSTALL_AND_UPDATE.md) · [패키징·GitHub 업로드](docs/BUILD_AND_GITHUB.md)

## 지원 형식

| 구분 | 확장자 예 | 방식 |
| --- | --- | --- |
| PDF | `.pdf` | 보기·페이지 정리·글자/그림/선 편집 |
| 이미지 | `.jpg` `.jpeg` `.png` `.webp` `.tif` `.tiff` `.bmp` `.gif` | 직접 보기 |
| 압축 이미지 | `.zip` `.cbz` | 압축파일 안의 이미지를 페이지로 보기 |
| 일반 텍스트 | `.txt` `.py` `.md` `.log` 등 | 페이지 읽기·원본 텍스트 편집/저장 |
| 한글 문서 | `.hwp` `.hwpx` | PDF로 간편 변환해 보기 |
| Office 문서 | `.doc` `.docx` `.xls` `.xlsx` `.ppt` `.pptx` 등 | LibreOffice로 PDF 변환 후 보기 |
| CAD·디자인 | `.dxf` `.psd` | 형식별 PDF 변환 후 보기 |

v3.13.39 소스에는 **DWG·AI·EPS·PS 직접 읽기**가 포함되어 있지 않습니다. 해당 문서는 원래 프로그램에서 PDF로 저장해 열어 주세요. GIF의 PDF 저장·인쇄는 첫 프레임을 사용합니다.

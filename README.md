# The Viewer 정

광고 배너 없는 Windows용 PDF·사진 뷰어입니다. 페이지를 정리하고, 원본과 수정본을 좌우로 열어 검토할 수 있습니다.

**[최신 정식 버전 다운로드와 변경사항](https://github.com/faintstar85-source/the-viewer/releases/latest)** · [오류 제보와 기능 요청](https://github.com/faintstar85-source/the-viewer/issues) · [개발자 블로그](https://blog.naver.com/faintstar)

처음 사용하는 분은 최신 릴리스에서 **설치 EXE**를 받으세요. 설치 배포본은 Python을 따로 설치하지 않고 사용할 수 있습니다.

## 3.12.4에서 바뀐 점

- 설치 과정에서 PDF/JPG 열기 등록을 선택하고 Windows 기본 앱 설정으로 연결할 수 있습니다.
- 정 메뉴에 업데이트 탭을 추가했습니다. 인터넷에서 새 버전과 수정 내역을 확인할 수 있습니다.
- 업데이트 설치는 다운로드 → 크기와 SHA-256 검사 → 작업 저장 확인 → 뷰어 종료 → 설치로 이어집니다.
- 다운로드 취소나 창 닫기 시 자동 설치 연결을 취소합니다.
- 비교 도움말 버튼과 설정의 긴 정적 사용법 문단을 제거해 화면을 정리했습니다.

3.12.4는 설치·파일 연결·업데이트 흐름과 화면 안내를 정리한 버전입니다. 비교 알고리즘은 이전 3.12.3과 같으며, 차이 검출 정확도를 개선한 버전으로 안내하지 않습니다.

현재 프로그램 내부 업데이트는 **전체 설치 EXE를 내려받는 방식**입니다.

## 주요 기능

아래 이미지는 AI로 만든 기능 설명용 일러스트입니다. 실제 프로그램 화면이나 검출 성능을 보여 주는 자료는 아닙니다.

### 1 PDF와 사진을 한 화면에서 확인

![PDF와 사진 보기 및 광고 없는 프로그램 화면을 설명하는 일러스트](assets/guide/01_viewer.png)

문서와 사진을 열고, 썸네일에서 필요한 쪽을 찾아 크게 확인합니다.

PDF, JPG, PNG 등 문서와 이미지 파일을 열 수 있습니다. 파일이나 폴더를 드래그해 넣고, 썸네일을 선택하거나 페이지 이동 키로 내용을 확인합니다. 썸네일 영역을 접으면 크게 보기 영역을 넓힐 수 있습니다.

ZIP과 CBZ에 모아둔 이미지도 페이지를 넘기며 읽을 수 있습니다. TXT와 PY 같은 일반 텍스트 파일은 페이지로 읽거나 본문을 수정해 저장할 수 있습니다.

시작 화면의 [+]에 파일을 드롭하거나 더블클릭해 파일을 선택하세요.

### 2 페이지 정리와 PDF 편집

![페이지 순서 변경과 JPG 추가 및 글자 그림 편집을 설명하는 일러스트](assets/guide/02_edit.png)

여러 자료를 모아 순서를 바꾸고, 필요한 내용을 편집해 PDF로 저장합니다.

썸네일에서 페이지를 드래그해 순서를 바꾸고, 다른 PDF나 JPG를 원하는 위치에 추가할 수 있습니다. 페이지 복사와 붙여넣기, 작업 목록에서 페이지 제외도 지원합니다.

PDF의 텍스트와 비트맵 그림을 선택해 수정하거나, 문자를 추가하고 그림의 위치와 크기를 조절할 수 있습니다. 정리한 결과는 PDF로 저장하거나 인쇄합니다. 스캔 사진 안의 글자를 OCR로 추출해 편집하는 기능은 현재 포함되어 있지 않습니다.

썸네일에 파일 드롭 → 순서 정리 → PDF 저장. 일반 텍스트의 원본 저장과 PDF 결과 저장은 별도 기능입니다.

### 3 좌우 듀얼 보기와 동시 이동

![좌우 보기와 붉은 클립 및 동시 스크롤을 설명하는 일러스트](assets/guide/03_dual.png)

원본과 수정본을 양옆에 놓고 같은 위치를 따라가며 확인합니다.

썸네일 쪽의 듀얼 보기 버튼을 누르면 오른쪽 보기 창이 열립니다. 오른쪽 창에도 다른 PDF나 사진을 드래그해 넣을 수 있습니다. 두 보기 창은 각각 자료를 읽고 이동할 수 있습니다.

양쪽 클립을 잠그고 동시 이동을 켜면 페이지 이동, 확대와 스크롤을 함께 움직일 수 있습니다. 잠긴 클립은 붉게 표시되고, 동시 이동은 가운데 마우스 휠 표시로 확인할 수 있습니다. 자동 정렬은 시작 위치가 다른 자료의 공통 영역을 맞추는 데 사용합니다.

듀얼 보기 열기 → 오른쪽 파일 넣기 → 양쪽 클립 잠금 → 동시 이동과 자동 정렬 확인.

### 4 검토 모드에서 차이 후보 확인

![원형 차이 후보와 분석 보류를 설명하는 일러스트 실제 검출 사례가 아님](assets/guide/04_review.png)

확인할 위치를 원형으로 표시하고, 정렬이 불확실하면 분석을 보류합니다.

차이 비교를 켜면 현재 표시 중인 두 쪽을 대조해 변경이 의심되는 위치를 표시합니다. 후보는 커졌다 작아지는 원형으로 보이며, 이전 후보와 다음 후보로 이동하면서 원본과 수정본을 확인할 수 있습니다.

자동 정렬이 불확실하거나 가장자리 내용이 잘린 경우에는 분석 보류로 표시합니다. 보류 상태의 임시 후보는 주황색으로 구분합니다. 정렬 상태와 원본 내용을 확인한 뒤 다시 분석할 수 있습니다.

검토 대상은 현재 열린 두 쪽입니다. 후보가 없는 경우에도 문서 전체의 동일성이 확정되는 것은 아닙니다. 작은 변경은 놓칠 수 있고 차이가 아닌 위치도 후보로 표시될 수 있으므로, 표시된 후보와 실제 내용을 함께 확인하세요.

수정 전후 PDF, 출력본 스캔, 화면 캡처와 사진의 변경 위치를 검토할 때 사용할 수 있습니다.

### 5 번역과 한글 변환 후 바로 검토

![PDF 번역과 HWPX 변환 및 결과 검토를 설명하는 일러스트](assets/guide/05_conversion.png)

변환한 결과를 원본 옆에 열어 문구와 배치를 이어서 확인합니다.

DeepL API 키를 설정하면 PDF를 한국어로 번역할 수 있습니다. 한글 변환 기능은 PDF의 글, 표와 그림을 한글 편집용 HWPX로 옮기는 데 사용합니다. 번역이나 한글 변환의 저장이 끝나면 원본과 결과를 좌우 검토뷰로 자동으로 엽니다.

번역에는 인터넷 연결과 DeepL API 키가 필요하며 문서가 DeepL 서비스로 전송됩니다. 서비스 이용 조건과 사용량 한도가 적용됩니다. 한글 결과의 간편 보기는 실제 한컴 출력과 배치가 다를 수 있으므로, 복잡한 표와 도형은 결과 파일을 함께 확인하세요.

번역 → 결과 PDF 저장 → 좌우 검토. 한글 변환 → HWPX 저장 → 좌우 검토.

### 6 설치와 프로그램 내부 업데이트 확인

![설치 파일 다운로드와 설정 내 업데이트 확인을 설명하는 일러스트](assets/guide/06_update.png)

설치 파일로 시작하고, 이후에는 설정에서 새 버전을 확인합니다.

처음 사용할 때는 GitHub Releases의 설치 EXE를 실행합니다. 설치 과정에서 PDF와 JPG 열기 등록을 선택할 수 있으며, 기본 앱 지정은 Windows 설정에서 The Viewer를 선택해 마무리합니다. 설치 패키지의 대상은 Windows 10 2004 이상 또는 Windows 11의 x64 PC입니다.

정 → 업데이트 → 인터넷 업데이트 확인에서 새 버전을 확인합니다. 새 설치 파일을 다운로드하고 검증한 뒤, 작업 저장을 확인하고 뷰어를 종료해 설치를 진행합니다. 현재 3.12.4의 업데이트는 전체 설치 EXE를 사용하는 방식입니다.

포터블 ZIP을 사용할 경우에는 압축을 풀고 The_Viewer.exe를 실행합니다. 실행파일과 _internal 폴더를 함께 유지하세요. 변환 기능은 배포 패키지에 포함된 엔진 구성에 따라 사용할 수 있습니다.


## 지원 형식

| 구분 | 확장자 | 지원 방식 |
| --- | --- | --- |
| PDF | .pdf | 보기와 페이지 정리 및 PDF 편집 |
| 이미지 | .jpg .jpeg .png .webp .tif .tiff .bmp .gif | 직접 보기. GIF의 PDF 저장과 인쇄는 첫 프레임 기준 |
| 압축 이미지 | .zip .cbz | 압축파일 안 이미지를 페이지로 보기 |
| 일반 텍스트 | .txt .py .md .log 등 | 페이지 읽기와 본문 편집 및 저장 |
| 한글 문서 | .hwp .hwpx | 간편 변환 보기. 원본 한컴 배치와 차이 가능 |
| Office 문서 | .doc .docx .xls .xlsx .ppt .pptx 등 | LibreOffice 엔진으로 PDF 변환 후 보기 |
| CAD와 디자인 | .dwg .dxf .psd .ai .eps | 형식별 변환 또는 합성 이미지 표시. 엔진과 원본 구성에 따른 제한 |

Office와 CAD 등의 형식은 파일을 직접 선택하거나 드롭해 엽니다. 복잡한 서식이나 CAD 요소는 원래 편집 프로그램의 표시와 차이가 있을 수 있습니다.

## 시작과 업데이트

1. 최신 릴리스의 설치 EXE를 실행합니다.
2. 설치에서 PDF/JPG 열기 등록을 선택한 경우, Windows 기본 앱 설정에서 The Viewer를 선택합니다.
3. 파일을 드래그해 넣거나 시작 화면의 [+]를 더블클릭해 엽니다.
4. 새 버전은 정 → 업데이트 → 인터넷 업데이트 확인에서 확인합니다.

대상은 Windows 10 2004 이상 또는 Windows 11의 x64 PC입니다. ZIP 배포본은 동봉 파일을 함께 압축 해제하세요. EXE 배포본의 The_Viewer.exe와 _internal 폴더 등 동봉 파일을 함께 유지합니다.

## 새 버전 알림

GitHub 계정으로 이 저장소의 Watch → Custom → Releases를 선택하면 릴리스 알림을 구독할 수 있습니다. 프로그램 내 업데이트 확인도 사용할 수 있습니다.

## Python으로 실행

소스 실행을 원하는 경우 저장소의 requirements.txt와 필요한 변환 엔진을 준비합니다.

```console
py -m pip install -r requirements.txt
py pdf_page_dragger.py
```

PDF/JPG 기본 보기와 Office·CAD 등의 변환 기능은 필요한 구성요소가 다릅니다. 구체적인 배포 구성은 해당 릴리스의 VERSION_GUIDE.txt에서 확인하세요. DeepL API 키는 정 → 번역에서 개인별로 등록합니다.

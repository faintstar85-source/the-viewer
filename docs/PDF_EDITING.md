# PDF 글자·그림·선 편집

**문서 기준: v3.13.38.** [사용 안내](PROGRAM_GUIDE.md) · [처음 화면](../README.md)

편집은 주 보기의 **글/그림 편집**에서 수행합니다. 듀얼 오른쪽 보기는 읽기 전용입니다.

## 글상자 수정과 이동

1. 수정할 글자를 선택합니다.
2. 상자 안쪽에서 글을 바로 입력합니다. 글꼴·크기·굵게·색상도 조절할 수 있습니다.
3. 상자 테두리를 드래그해 옮기고, 손잡이를 드래그해 상자 크기를 조절합니다.
4. 상자 밖을 클릭하거나 편집을 끝내면 수정 내용을 적용합니다.

선택 상자의 **↔** 버튼을 켜면 안쪽을 잡아도 상자를 이동할 수 있습니다. 상자 전체를 복사하려면 **복사** 버튼을 사용합니다. **붙이기**로 만든 상자는 독립적으로 수정할 수 있습니다.

문자추가로 넣은 글상자도 이동·크기 조절·복사 후 개별 수정이 가능합니다.

## 키보드로 미세 이동

개체가 선택된 편집 상태에서 사용합니다.

| 키 | 이동량 |
| --- | --- |
| 방향키 | 0.5 mm |
| Ctrl + 방향키 | 0.1 mm |
| Shift + 방향키 | 5 mm |

텍스트 상자를 방향키로 움직일 때 마지막 이동 후 약 **3.5초** 동안 이동 상태를 유지해 바로 글자 입력 커서로 바뀌는 흐름을 줄였습니다.

## 그림·선·표 테두리

- 그림을 선택해 드래그로 옮기고 손잡이로 크기를 조절합니다.
- 수평·수직 선은 끝점 손잡이로 길이를, 선의 위·아래 또는 좌·우 가운데 손잡이로 두께를 조절합니다.
- 선을 조절할 때 수평 또는 수직 방향을 유지합니다.
- 표 테두리와 선 묶음은 선택 손잡이로 가로·세로 크기를 조절합니다.
- 선과 표 테두리도 복사해 다른 페이지에 붙여넣을 수 있습니다.

얇은 선을 집기 어려우면 우클릭 범위 선택을 사용합니다. 여러 개의 얇은 채움 사각형을 하나의 경로로 묶은 PDF 표선도 선으로 인식합니다. 그림으로 들어간 표는 하나의 이미지이므로 내부 선을 개별 선 개체처럼 편집할 수 없습니다. 표 안의 글자는 글상자로 따로 선택해 수정합니다.

## 여러 개체 선택과 정렬

**글/그림 편집**에서 우클릭한 채 드래그하면 글자·선·그림을 범위로 선택합니다. 객체 전체를 둘러싸지 않아도 범위에 일부가 걸치면 선택됩니다. 얇은 선에는 화면 기준 약 3px의 여유가 있어 살짝 어긋난 범위도 잡습니다. 확대 배율에 맞춰 이 여유를 환산합니다.

페이지 바깥의 표시 여백에서도 드래그를 시작할 수 있습니다. Ctrl을 누른 채 범위를 잡으면 기존 선택을 유지하면서 추가하거나 이미 선택된 객체를 해제합니다. Ctrl+좌클릭으로 하나씩 골라 해제할 수도 있습니다.

선택 도구 모음에서 다음 작업을 적용합니다.

| 버튼 | 동작 |
| --- | --- |
| 왼쪽 정렬 | 글줄 또는 개체의 왼쪽 끝 맞춤 |
| 가운데 정렬 | 글줄 또는 개체의 가로 가운데 맞춤 |
| 세로 간격 | 위에서 아래로 개체 사이의 빈 간격 균등 조절 |
| 가로 간격 | 같은 글줄 안에서 가로 빈 간격 균등 조절 |
| 글상자 합치기 | 선택한 문자 개체를 하나의 편집 상자로 구성 |

왼쪽 정렬 버튼을 우클릭하면 위쪽 끝 맞춤, 가운데 정렬 버튼을 우클릭하면 세로 가운데 맞춤을 사용합니다.

같은 글줄을 구성하는 문자 조각은 줄 단위로 취급합니다. 가로 간격을 조절할 때 서로 다른 글줄을 한 줄로 펼치지 않습니다.

여러 개체를 선택한 바깥 테두리의 손잡이를 끌면 **개체 크기를 유지하면서 배치 간격**을 늘리거나 줄입니다. 페이지 경계와 개체 겹침을 확인해 조절 가능한 범위까지만 적용합니다.

## 조각난 글자를 문장으로 수정

1. 하나의 문장이나 문단으로 만들 문자 개체들을 선택합니다.
2. **글상자 합치기**를 누릅니다.
3. 합쳐진 상자에서 문장을 바로 수정합니다.

읽는 순서와 줄바꿈을 유지하며, **첫 글자의 서식**을 기준으로 합칩니다. 선택한 각 글자의 서로 다른 서식을 모두 보존하는 기능은 아닙니다. 합친 결과는 Ctrl+Z로 되돌릴 수 있습니다.

## 다른 페이지의 같은 위치에 붙이기

1. 개체를 선택하고 Ctrl+C 또는 복사 버튼으로 복사합니다.
2. 대상 페이지를 엽니다.
3. 글/그림 편집 상태에서 Ctrl+V 또는 붙이기로 붙여넣습니다.

개체의 **원래 X/Y 좌표**를 기준으로 붙습니다. 빈 페이지도 사용할 수 있습니다. 대상 페이지가 작아 원래 좌표의 개체가 페이지 밖으로 나가면 붙여넣기를 제한합니다.

여러 개체를 함께 복사할 때는 각 개체의 위치와 상대 배치를 함께 유지합니다.

## 덮기와 스포이드

**흰색 덮기**의 색상을 선택하거나 스포이드로 문서의 색상을 집을 수 있습니다. 스포이드 이동 중 색상 버튼과 미리보기에 색상·RGB 값이 표시되고, 클릭하면 적용합니다. Esc 또는 우클릭으로 스포이드를 취소합니다.

## 저장과 되돌리기

편집 결과는 **Ctrl+S** 또는 저장 버튼으로 PDF 사본에 저장합니다. 이동이나 글자 수정이 반영 중이면 반영이 끝난 뒤 저장을 이어갑니다. 여러 페이지를 연 경우 현재 작업 순서의 전체 페이지를 저장합니다. Ctrl+Z로 편집을 되돌릴 수 있습니다.

v3.13.30은 글자와 표선을 함께 이동한 뒤 PDF를 다시 기록할 때 생기는 미세한 좌표 반올림을 고려해 원본 선의 연결을 다시 대조합니다. 원본 연결을 확인할 수 없는 구성은 편집 오류로 알리고 원본을 보존합니다. 수정 후 종료 질문의 **예**는 저장 진행, **아니오**는 저장하지 않고 종료, **취소**는 작업 계속입니다.

스캔 이미지 안의 글자와 인식되지 않는 PDF 구성요소는 직접 글자 수정 대상이 아닙니다. 해당 위치에 문자추가·덮기 등을 적용할 수 있습니다.

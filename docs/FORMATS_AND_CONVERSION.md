# 지원 형식·변환·인쇄

**문서 기준: v3.13.38.** [사용 안내](PROGRAM_GUIDE.md) · [처음 화면](../README.md)

## 파일 형식

| 구분 | 지원 확장자 | 처리 |
| --- | --- | --- |
| PDF | `.pdf` | 보기·페이지 정리·글자/그림/선 편집 |
| 이미지 | `.jpg` `.jpeg` `.png` `.webp` `.tif` `.tiff` `.bmp` `.gif` | 직접 보기 |
| 압축 이미지 | `.zip` `.cbz` | 압축파일 안의 이미지를 페이지로 보기 |
| 일반 텍스트 | `.txt` `.text` `.py` `.pyw` `.md` `.markdown` `.log` 등 | 읽기 페이지 생성·원본 텍스트 편집 |
| 한글 | `.hwp` `.hwpx` | 간편 PDF 변환 후 보기 |
| Word | `.doc` `.docx` `.docm` | LibreOffice로 PDF 변환 후 보기 |
| Excel | `.xls` `.xlsx` `.xlsm` | LibreOffice로 PDF 변환 후 보기 |
| PowerPoint | `.ppt` `.pptx` `.pptm` | LibreOffice로 PDF 변환 후 보기 |
| CAD | `.dxf` | 도면을 PDF로 변환 후 보기 |
| Photoshop | `.psd` | 합성 이미지를 PDF로 변환 후 보기 |

일반 텍스트는 JSON·XML·YAML·CSV·HTML·CSS·JS·SQL·BAT 등도 텍스트로 읽습니다. 해당 코드나 명령을 실행하는 기능은 아닙니다. 현재 파일 크기 한도는 16 MiB입니다.

v3.13.38 소스에서 **DWG·AI·EPS·PS 직접 읽기**는 제외되어 있습니다. 원래 프로그램에서 PDF로 저장한 파일을 여세요.

GIF의 PDF 저장·인쇄는 첫 프레임을 사용합니다. PSD 읽기는 레이어별 편집을 제공하지 않습니다.

## Office와 한글 문서 읽기

Office 문서는 LibreOffice로 PDF를 만든 뒤 읽습니다. 기본 빌드에서는 LibreOffice를 동봉하지 않으며, PC에 설치된 LibreOffice를 사용할 수 있습니다.

HWP/HWPX는 간편 변환 보기입니다. 복잡한 표·도형·배치는 한컴에서 본 원본과 다를 수 있습니다. 변환 결과를 업무에 사용할 때 원본과 함께 확인하세요.

## PDF 한국어 번역

1. **정 → 설정 → 번역**에서 DeepL API 키와 저장 관련 설정을 입력합니다.
2. PDF가 모두 읽힌 뒤 번역을 시작합니다.
3. 결과 PDF 저장 후 원본과 결과를 좌우 검토뷰에서 확인합니다.

번역에는 인터넷 연결과 API 키가 필요합니다. 문서는 DeepL 서비스로 전송되며, 선택한 API 요금제와 사용량 조건이 적용됩니다.

## PDF를 한글 편집용 문서로 변환

한글 변환은 PDF의 글·표·그림을 한글 편집용 문서로 옮기는 기능입니다. 전체 또는 선택 페이지를 대상으로 설정하고 결과를 저장합니다.

변환 결과의 간편 보기와 실제 한컴 출력은 다를 수 있습니다. 복잡한 표와 도형은 결과 파일에서도 확인하세요. 스캔 이미지의 문자를 OCR로 인식해 편집 가능한 본문으로 만드는 기능은 포함되어 있지 않습니다.

## PDF 저장과 인쇄

정리한 페이지를 한 PDF로 저장하거나 페이지별 PDF로 저장할 수 있습니다. 인쇄창에서 페이지 범위, A4/A3 용지, 방향, 배치, 부수 등을 설정합니다.

원본 크기와 출력 배치를 확인한 뒤 인쇄하세요. 텍스트 파일의 원본 저장은 PDF 저장과 별도로 사용합니다.

기능 기준: [뷰어 소스](../pdf_page_dragger.py). 배포에 포함된 구성은 해당 릴리스의 버전 안내를 확인하세요.

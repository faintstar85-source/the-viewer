# The Viewer 사용 안내

**문서 기준: v3.13.30.** [다운로드](https://github.com/faintstar85-source/the-viewer/releases/latest) · [처음 화면으로](../README.md)

## 파일 열기와 페이지 정리

1. 시작 화면의 **[+]**에 파일을 드롭하거나 더블클릭해 파일을 선택합니다.
2. 썸네일을 선택해 내용을 확인합니다.
3. 썸네일을 드래그해 순서를 바꾸고, 필요한 PDF·사진을 추가합니다.
4. 정리한 결과는 PDF로 저장하거나 인쇄합니다.

페이지를 작업 목록에서 제외하는 동작과 원본 파일을 삭제하는 동작은 다릅니다. 텍스트 파일의 원본 저장도 PDF 결과 저장과 구분합니다.

## 파일별 시작 화면

| 파일 | 처음 화면 |
| --- | --- |
| ZIP·CBZ | 1|2 두 장 보기 |
| PDF·사진 | 주 보기와 썸네일 |
| PY·PYW·HTML·HTM | 원본 텍스트 편집기 |

## 페이지 회전과 번호

썸네일 우클릭 메뉴에서 **왼쪽 90도 회전 / 오른쪽 90도 회전**을 사용합니다. 복사·붙여넣기는 Ctrl+C/V 단축키를 사용합니다.

번호를 넣을 페이지를 선택한 뒤 **[쪽] → 쪽번호 생성**을 누릅니다. 첫 선택 페이지의 미리보기에서 위치를 정하고 **쪽번호 디자인**에서 글꼴·크기·숫자 양옆 문구를 조절합니다. 선택한 순서로 번호를 넣으며, **[쪽] → 쪽번호 삭제**로 The Viewer에서 생성한 번호를 삭제합니다.

## PDF 편집 시작

주 보기에서 **글/그림 편집**을 선택합니다. 글자는 상자 안에서 바로 입력하고, 테두리와 손잡이로 배치를 조절합니다.

여러 개체는 우클릭 드래그로 범위를 잡습니다. 선택된 개체는 함께 이동·복사하거나 왼쪽·가운데 정렬, 가로·세로 간격 조절을 적용합니다.

## 텍스트 파일 읽기와 편집

TXT·PY·MD 등의 일반 텍스트는 줄바꿈을 반영해 읽기 페이지로 표시합니다. **텍스트 읽기 설정**에서 글자 크기와 줄 간격을 조절할 수 있습니다.

본문 편집은 원본 텍스트를 수정하는 기능입니다. PDF 위에 글상자를 추가하는 기능과 저장 대상이 다릅니다. 현재 일반 텍스트 읽기의 파일 크기 한도는 **16 MiB**입니다. PY 파일을 열어 읽는 동작은 그 코드를 실행하지 않습니다.

## Python 코드 편집

Python 파일의 편집기에는 줄 번호·구문 강조·들여쓰기와 찾기를 제공합니다. 함수 목록에서 함수·메서드 전체를 선택하고 **함수 교체**로 새 코드를 넣을 수 있습니다. **전후 비교**에서 수정 전과 현재 내용을 대조합니다.

**문법 검사**와 Python 파일 저장 전 검사는 코드 문법을 확인합니다. 실행 결과나 프로그램 동작을 보증하는 검사는 아닙니다. PY 파일을 읽거나 수정하는 동작으로 코드를 실행하지 않습니다.

## 설정과 종료

**정 → 설정**에서 기본 화면, 번역, 한글 변환, 단축키, 텍스트 읽기·편집, 업데이트 항목을 조절합니다.

듀얼 보기와 1|2 전환 애니메이션은 기본적으로 꺼져 있습니다. **기본 → 듀얼 보기 / 1|2 전환 애니메이션**에서 켤 수 있습니다.

수정 후 종료할 때는 **예 / 아니오 / 취소**로 저장 진행, 저장하지 않고 종료, 작업 계속을 선택합니다.

## 확인이 필요한 경우

- 스캔 이미지의 문자는 텍스트 개체가 아니므로 직접 글자 편집 대상이 아닙니다.
- 다른 페이지에 같은 좌표로 붙일 때 대상 페이지가 작으면 개체가 페이지 밖으로 나갈 수 있습니다. 이 경우 붙여넣기를 제한합니다.
- 비교 결과는 현재 두 쪽의 차이 후보입니다. 원본 내용을 함께 확인하세요.
- 변환한 문서는 사용 글꼴과 복잡한 서식에 따라 원본과 차이가 생길 수 있습니다.

기능 기준은 [뷰어 소스](../pdf_page_dragger.py)이며, 버전별 변경은 [수정 기록](../CHANGELOG.md)에서 확인합니다.

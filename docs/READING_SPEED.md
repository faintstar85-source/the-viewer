# v3.13.38 PDF 읽기 구조

[사용 안내](PROGRAM_GUIDE.md) · [뷰어 소스](../pdf_page_dragger.py)

이 문서는 첨부 소스에서 확인한 동작 구조입니다. v3.13.38의 속도 수치는 새로 측정하지 않았습니다.

- `_viewer_fast_pdf_worker`가 Qt GUI와 편집 코드 초기화보다 먼저 실행됩니다.
- 일반 PDF 페이지는 PDFium으로 읽고 RGB 데이터 또는 PNG로 반환합니다.
- pypdf에서 CropBox·MediaBox·회전·UserUnit 정보를 읽습니다.
- 양식 위젯이 있는 페이지는 내장 호환 코드로 표시합니다. 편집 요청도 이 코드를 사용합니다.
- PY 실행에서는 현재 Python 세션에서 생성한 임시 코드로 읽기 작업 프로세스를 시작합니다. EXE는 내장 진입점을 사용합니다.
- PDF 읽기 작업 프로세스의 검색 요청은 문자 일치 결과와 표시 좌표를 반환합니다.

## 패키징 검사와의 연결

패키징 v1.5.9는 v3.13.38에 `render` 요청을 사용합니다. PNG 응답, 일반 페이지·양식 페이지의 RGB와 기존 엔진 픽셀 일치, 검색 결과, 편집 정보 반환을 검사합니다. 검사가 실패하면 Windows 빌드의 성공 판정을 내리지 않습니다.

GitHub 매니저 v2.1.2는 `_viewer_fast_pdf_worker`를 인식하여 `pypdfium2==5.14.0`을 requirements.txt에 기록합니다. 이전 버전의 함수 이름만 보고 5.3.0으로 내리는 경우를 수정했습니다.

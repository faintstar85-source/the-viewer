# v3.13.39 PDF 읽기 구조

[사용 안내](PROGRAM_GUIDE.md) · [뷰어 소스](../pdf_page_dragger.py)

## 이번 변경

| 항목 | v3.13.38 | v3.13.39 |
| --- | --- | --- |
| 최근 화면 캐시 한도 | 8쪽·64MiB | 32쪽·256MiB |
| PDF 미리 읽기 위치 | 다음 읽기 위치 | 다음·이전 읽기 위치 |
| 기본 PDF 미리보기 크기 | 1800px 기준 | 화면의 물리 픽셀 크기에 맞춤 |

캐시는 주 보기와 듀얼 보기에서 공유하며 필요할 때 채웁니다. 쪽수 또는 이미지 메모리 한도를 넘으면 오래 사용하지 않은 항목을 제거합니다. 256MiB는 이 캐시의 상한이며 프로그램 전체 메모리 상한은 아닙니다.

기본 PDF 미리보기의 긴 변은 화면 크기와 화면 배율을 반영해 128px 단위로 올림하며 1024~5000px 범위로 제한합니다. 확대할 때 캐시에 필요한 해상도가 없으면 다시 읽습니다. 이 변경은 표시용 화면에 적용됩니다.

PDF에서는 현재 페이지를 먼저 표시한 뒤 다음·이전 읽기 위치를 준비합니다. 이미지·압축 이미지의 미리 읽기는 기존의 앞으로 읽기 정책을 유지합니다. 파일 크기나 수정 시각이 달라진 원본에 이전 캐시를 재사용하지 않습니다.

## 기존 읽기 경로

- `_viewer_fast_pdf_worker`는 Qt GUI·편집 코드 초기화보다 먼저 실행됩니다.
- 일반 PDF 페이지는 PDFium으로 읽고 RGB 데이터 또는 PNG로 반환합니다.
- 양식 위젯 페이지와 편집 요청은 내장 호환 코드를 사용합니다.
- 현재 표시와 미리 읽기가 같은 페이지를 요청하면 진행 중인 작업의 결과를 재사용할 수 있습니다.

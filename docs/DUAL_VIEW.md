# 듀얼 보기와 비교

**문서 기준: v3.13.30.** [사용 안내](PROGRAM_GUIDE.md) · [처음 화면](../README.md)

## 듀얼 보기 열기

문서를 연 뒤 썸네일 쪽의 듀얼 보기 버튼을 누르거나 아래로 당겨 오른쪽 보기를 엽니다. 듀얼 보기 버튼으로 다시 접을 수 있습니다.

모드 버튼은 현재 모드를 **A|A** 또는 **1|2**로 표시합니다. 버튼을 눌러 다른 모드로 전환합니다.

| 모드 | 사용할 때 |
| --- | --- |
| **A\|A 검토 모드** | 원본과 수정본 등 서로 다른 자료 비교 |
| **1\|2 두 장 모드** | 같은 작업 목록의 두 쪽을 나란히 읽기 |

## A|A 검토 모드

1. 주 보기에서 원본 자료를 엽니다.
2. 듀얼 보기를 열고 오른쪽에 비교할 자료를 드롭합니다.
3. 필요한 페이지를 각각 선택합니다.
4. 양쪽 클립을 잠그고 동시 이동·자동 정렬 상태를 확인합니다.

잠긴 클립은 붉게 표시됩니다. 동시 이동을 켜면 페이지 이동·확대·스크롤을 함께 조절할 수 있습니다. 오른쪽 보기는 읽기 전용이며 편집은 주 보기에서 수행합니다.

## 1|2 두 장 모드

같은 작업 목록의 두 쪽을 좌우에 놓고 읽습니다. 쪽 이동 단위를 선택해 넘길 수 있습니다. 서로 다른 파일의 수정 전후 비교는 A|A 검토 모드를 사용합니다.

## 그림 사이 간격과 집중모드

1|2 모드에서는 두 그림 사이의 안쪽 페이지 화살표를 숨깁니다. 하단의 삼각형 손잡이를 왼쪽으로 끌면 그림 사이 간격을 줄이고 오른쪽으로 끌면 늘립니다.

상단 오른쪽의 **집중모드**를 누르면 상·하단 도구와 페이지 화살표를 숨겨 그림 표시 영역을 넓힙니다. 오른쪽 그림의 **맨 오른쪽 위**에 마우스를 올리면 해제 화살표가 나타납니다. 이 화살표를 클릭하거나 **Esc**를 누르면 기존 화면으로 돌아옵니다.

집중모드에서도 지정된 페이지 이동·확대 단축키를 사용합니다. 다른 대화창이나 팝업이 열린 경우 Esc는 그 창을 닫는 기존 동작을 먼저 수행합니다.

파일명과 쪽수는 평상시 화면 하단의 한 줄에 표시합니다. 검토 안내는 약 10초 뒤 숨기며 검토모드를 끝낼 때도 정리합니다.

## 차이 후보 검토

차이 비교를 켜면 **현재 표시 중인 두 쪽**에서 변경이 의심되는 위치를 원형 후보로 표시합니다. 이전·다음 후보 버튼으로 이동하며 원본 내용을 확인합니다.

자동 정렬이 불확실하거나 내용이 잘린 경우에는 분석 보류 상태를 표시합니다. 보류 상태의 임시 후보는 주황색으로 구분합니다.

이 결과는 문서 전체의 동일성 판정이 아닙니다. 후보가 없더라도 작은 변경이 남아 있을 수 있고, 차이가 아닌 위치가 후보로 표시될 수도 있습니다. 실제 내용을 함께 확인하세요.

## 애니메이션 설정

듀얼 보기 펼치기·접기와 1|2 쪽 전환 애니메이션은 **기본값이 꺼짐**입니다.

**정 → 설정 → 기본 → 듀얼 보기 / 1|2 전환 애니메이션**에서 켤 수 있습니다.

기능 기준: [뷰어 소스](../pdf_page_dragger.py).

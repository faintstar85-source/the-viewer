# The Viewer v3.13.30

## 표 선택과 혼합 편집 저장

- 우클릭 드래그 범위에 조금만 걸친 그림·글자·선도 선택합니다.
- 얇은 선에는 화면 기준 약 3px의 선택 여유를 주며, 페이지 바깥 여백에서도 범위 선택을 시작합니다.
- Ctrl 범위 선택으로 기존 단일 선택을 유지하면서 추가·해제합니다.
- 여러 얇은 채움 사각형을 하나의 PDF 경로로 저장한 표선을 편집 가능한 선으로 인식합니다.
- 글자와 표선을 함께 이동한 뒤 재기록할 때 미세한 좌표 반올림 때문에 선 정보가 변경됐다는 오류를 수정했습니다.
- 기존 선의 색상·두께와 선택하지 않은 선·글자를 유지하며 편집 결과를 사본 PDF로 저장합니다.

## 최근 추가된 읽기·편집 기능

- 1|2 집중모드: 오른쪽 그림 맨 오른쪽 위에 마우스를 올리면 해제 화살표가 표시되고, 클릭·Esc로 복귀합니다.
- ZIP·CBZ는 두 장 보기, PDF·그림은 주 보기+썸네일, PY·HTML은 텍스트 편집기로 시작합니다.
- 페이지 번호 생성·삭제와 썸네일의 좌우 90도 회전.
- Python 함수 선택·교체, 수정 전후 비교, 저장 전 문법 검사.
- 압축 이미지의 다음 장 미리 읽기와 하단 한 줄 파일명·쪽수 표시.

## 검증

제공된 3쪽 PDF로 표선 인식, 부분 범위 선택, Ctrl 선택 조절, 글자·선 혼합 이동, 연속 선 편집, 다른 페이지 복사·붙여넣기, 편집 직후 Ctrl+S와 저장 PDF 재열기를 점검했습니다. 원본 PDF가 변경되지 않는 것도 확인합니다.

이번 파일 묶음은 소스·제작 PY·Markdown 문서입니다. 실제 Windows 설치 EXE는 패키징 도구로 생성합니다.

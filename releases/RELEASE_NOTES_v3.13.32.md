# The Viewer v3.13.32

PDF 읽기 작업을 GUI와 편집 모듈의 초기화보다 먼저 시작하도록 바꿨습니다. 원본 파일을 직접 표시하고, 첫 화면에서 편집용 문서 복사·재저장 비용을 줄입니다. PY 실행에서는 작은 읽기 진입점을 사용합니다.

## 변경 내용

- 읽기 화면은 PDFium 5.14.0과 RGB 전달을 사용합니다. 소수점 페이지 좌표·회전·UserUnit과 기존 해상도를 유지합니다.
- 양식·위젯 주석이 있는 페이지와 편집 요청은 같은 작업 프로세스에서 기존 코드로 전환합니다.
- 원본 변경 시 읽기 문서를 갱신하고, 편집과 종료 전에 읽기 핸들을 해제합니다.
- 패키징 PY v1.5.8과 GitHub 업데이트 PY v2.1.1에 새 PDFium 의존성을 반영했습니다.

## 확인 결과

첨부 PDF의 첫 이미지 수신은 버전별 5회 중앙값 **560ms → 118ms**입니다. 앞서 안내한 61ms는 최소 시제품 수치입니다. 사진 시험 PDF의 후속 쪽에서는 개선을 확인하지 않았습니다. [측정 조건과 원자료](../docs/READING_SPEED.md).

읽기·듀얼 보기·표 편집·같은 좌표 복사·저장 관련 80개 기능 시험을 통과했습니다. 패키징의 21개 실행 검사도 완료했습니다(Linux 19개 통과·Windows 및 미동봉 Office 2개 해당 없음). 양식 호환 화면과 기존 엔진의 픽셀 일치를 포함합니다.

Windows EXE는 제작 PC에서 v1.5.8 패키징 PY로 다시 빌드하고 확인해야 합니다. 이번 전달은 소스와 문서이며, Windows 설치 EXE나 원격 GitHub 업로드를 포함하지 않습니다.

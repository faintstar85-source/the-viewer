# The Viewer v3.13.31

사진이 포함된 PDF에서 화면을 전달할 때 수행하던 PNG 압축·해제를 제거했습니다. PDF·JPG의 주 보기와 미리 읽기 화면으로 썸네일을 만들어 같은 쪽을 다시 해독하는 작업을 줄입니다.

## 변경 내용

- PDF 화면을 RGB 픽셀로 전달합니다. 렌더링 해상도와 PDF 편집 엔진은 유지합니다.
- 최근 페이지 캐시를 최대 8쪽·64MiB로 유지하고 앞뒤 이동에 재사용합니다.
- 확대할 때 필요한 해상도가 캐시보다 크면 원본을 다시 읽습니다.
- 진행 중인 다음 PDF 쪽 읽기 결과를 주 보기에서 이어받습니다.

## 확인 결과

테스트 파일에서 PDF 첫 화면의 중앙값은 2.117초 → 1.390초로 줄었습니다. JPG 최초 해독은 약 0.09초로 개선이 확인되지 않았습니다. 썸네일 생성과 이미 읽은 JPG 이전 쪽 이동은 줄었습니다. [측정 조건·원자료 설명](../docs/READING_SPEED_v3.13.31.md).

읽기·캐시와 JPG 실제 창, 두 자료·ZIP 이동, 표 편집·복사·저장 및 집중모드 관련 57개 시험을 통과했습니다. 기존 PDF 표시와의 픽셀 일치, JPG 방향·원본 변경·확대, 글자와 표선 혼합 이동, 다른 페이지 붙여넣기, Ctrl+S와 저장 PDF 재열기를 포함합니다. 패키징 도구의 소스 인식 검사도 통과했습니다.

이 파일은 소스 변경 설명입니다. Windows EXE 빌드·설치와 원격 GitHub 업로드는 이번 실행 환경에서 수행하지 않았습니다.

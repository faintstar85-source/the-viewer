## 변경 내용

- 제작자가 별도 패키징 프로그램을 실행하지 않아도, GitHub에서 Windows 빌드·검사·설치 EXE·ZIP·Python 소스·SHA-256 파일을 준비하도록 배포 자동화를 추가했습니다.
- `release.json`의 버전과 소스 버전을 함께 관리합니다. `publish: false`이면 초안으로 준비하고, `publish: true`이면 검사한 첨부파일을 확인한 뒤 공개합니다.
- 프로그램 사용자는 기존 **정 → 업데이트**에서 새 설치 파일을 확인합니다.
- 저장소 본문에 3.13.40의 내부 페이지 이동 및 사진 인접 폴더 탐색 수정을 반영했습니다.
- 기존 저장소의 프로그램 아이콘을 유지했습니다.

## 확인 범위

GitHub의 해당 버전 Actions 결과에서 소스·완성 EXE·최종 위치 검사와 첨부파일 해시 검증 결과를 확인할 수 있습니다. 현장 PC 전체 동작이나 실제 프린터 출력을 검사했다는 의미는 아닙니다.

# The Viewer 3.13.48

## PDF 페이지 드래그

- 더뷰 창을 두 개 열고 한 창의 PDF 썸네일을 다른 창의 썸네일 사이에 놓으면 선택한 쪽이 삽입됩니다. 큰 미리보기 화면에 놓으면 현재 선택 뒤에 삽입합니다. 보내는 문서의 쪽은 삭제하지 않습니다.
- 받는 창이 자체 작업 사본을 완성한 다음 삽입하므로 보내는 창을 닫아도 받은 쪽을 계속 읽고 저장할 수 있습니다. 페이지 순서, 회전·주석, 되돌리기를 유지합니다.
- Windows 바탕화면·탐색기로 끌 때 드래그를 중단하고 다시 시작하던 방식을 제거했습니다. Windows가 파일 내용을 요청하면 완성된 사본을 전달하므로 준비 중 마우스를 놓아도 그 이유만으로 취소하지 않습니다.
- Esc·오른쪽 클릭과 작업 취소를 지원하고, 실패한 출력은 전달하지 않습니다. 원본을 덮어쓰거나 삭제하지 않으며 동일 드롭의 중복 삽입을 방지합니다.
- 기존 정 → 업데이트 경로, 설치 파일 이름·업데이트 검사와 빌드 검증을 유지합니다.

## 확인 범위

- 자동 회귀검사: 수신 사본 소유권, 원본 보존, 여러 쪽·중복 쪽 순서, 회전·주석, 변경된 원본 거부, 취소·실패·중복 드롭.
- Windows 설치 패키지 생성 전에 실제 패키징된 EXE에서 OLE 파일 형식, 인덱스별 PDF 파일 내용과 스트림을 검사합니다. 실제 사용자 PC의 탐색기 탭·네트워크 폴더·권한 차이는 별도 현장 확인 범위입니다.
- 별도 3.13.47 체크리스트 검토 브랜치의 미배포 편집 변경은 이번 드래그 수정에 섞지 않았습니다.

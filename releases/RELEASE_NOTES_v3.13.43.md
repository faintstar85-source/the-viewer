## 수정 내용

### Type3 글꼴이 있는 PDF의 편집 실패 수정

- 기존에는 PDF에 Type3 글꼴이 있으면 `Type3 글꼴은 원본 배치를 보존하는 개별 글자 편집을 지원하지 않습니다.`라는 오류로 글자 이동·삭제·교체가 중단됐습니다.
- Type3의 한 바이트 문자 코드와 원본 너비 배열을 읽고, 글꼴 변환 행렬 `FontMatrix`와 PDFium의 너비 정밀도를 반영하도록 수정했습니다.
- 원본 Type3 글자의 이동·삭제를 처리합니다. 문구나 서식을 새로 쓸 때는 기존 편집 기능과 같이 선택한 PC 설치 글꼴을 사용합니다.
- 같은 쪽에 Type3 글꼴이 있다는 이유로 일반 글꼴의 편집까지 막히던 경로도 수정했습니다.
- 메인 프로그램과 별도로 동봉된 편집 작업 프로세스의 호환 코드에 함께 반영하고, 두 경로의 글꼴 처리 코드가 일치하는지 자동 검사합니다.
- 편집 후 선택 밖 글자의 문자·좌표·경계가 유지되는지 확인한 뒤 작업 사본에 반영합니다. 문자 연결이나 너비 정보를 확정할 수 없는 경우에는 변경하지 않고 중단합니다.
- 문서·연필 편집 버튼, 사용 글꼴 우선 표시, 한글·번역 버튼의 기본 숨김 설정을 유지합니다.

## 검증

- Type3 한글 문자, 일반 글꼴 혼합, 다른 글꼴 배율, 소수 너비, 변형 행렬, 색을 지정하는 글자 프로그램을 포함한 재현 PDF 4종을 생성했습니다.
- 개별 글자 이동·삭제, 일반 글꼴 편집, 문구 교체, 저장 후 재열기와 잘못된 선택 거부를 검사합니다.
- 화면의 편집 기능이 사용하는 실제 PDF 작업 프로세스에 문자 교체 요청을 보내고 저장된 결과를 다시 검사합니다.
- 선택 밖 글자의 좌표·경계·픽셀, 원본 Type3 글꼴 프로그램과 원본 PDF 파일의 보존을 검사합니다.
- 한글을 지원하는 설치 글꼴이 있는 검사 환경에서는 한글 문구 교체도 검사하고, 검사 여부를 기록합니다.
- 이 검사를 소스·완성 EXE·최종 배포 위치의 Windows 패키징 검사에 추가했습니다. [해당 버전 Actions 결과](https://github.com/faintstar85-source/the-viewer/actions/workflows/release.yml)에서 통과 여부와 상세 검사 기록을 확인할 수 있습니다.

제보된 원본 PDF는 제공되지 않아 해당 파일 자체는 직접 검사하지 못했습니다. 모든 Type3 문서나 손상된 글꼴의 편집을 보장하는 변경은 아닙니다.

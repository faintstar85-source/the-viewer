## 수정 내용

### 숫자·짧은 문구 선택과 수정 개선

- 작은 숫자 주변에도 화면 기준 6픽셀의 선택 여유를 적용합니다. 가까운 글자 중 실제 위치에 가장 가까운 항목을 선택합니다.
- 한 줄의 짧은 문구를 선택하면 편집 도구 아래에 큰 입력칸을 표시합니다. 최대 64자까지 입력할 수 있습니다.
- 문구를 더블클릭하면 입력칸의 내용이 전체 선택되어 한두 자리 숫자를 바로 바꿀 수 있습니다.
- 입력칸 안의 방향키·Shift 선택은 글자 선택에 사용하며, Enter로 편집을 적용합니다. 기존 문서 위 직접 입력도 유지합니다.

### 보통 글씨가 자동으로 굵게 설정되던 판단 개선

- PDFium의 글자 획 두께 추정값만으로 굵게 설정하던 판단을 제거했습니다.
- 내장 TrueType/OpenType 글꼴의 실제 OS/2 굵기 정보를 먼저 읽습니다. 일반 굵기와 실제 Bold 글꼴을 구분합니다.
- 글꼴 프로그램에서 확인할 수 없을 때는 명시적인 글꼴 스타일 이름을 확인하며, 불명확한 경우에는 굵게를 자동으로 켜지 않습니다.
- 메인 프로그램과 별도로 동봉된 PDF 작업 프로세스에 동일한 변경을 반영하고 두 엔진의 일치 여부를 검사합니다.
- 3.13.43의 Type3 글자 이동·삭제·교체 오류 수정도 포함합니다.

## 검증

- 실제 글꼴과 다른 획 두께 값을 넣은 보통/굵은 숫자 PDF를 생성해, 보통 숫자는 보통으로, 실제 Bold 숫자는 굵게 표시되는지 검사합니다.
- 실제 PDF 작업 프로세스의 서식 분석 결과, 작은 숫자 주변 선택, 큰 입력칸과 문서 입력의 동기화, 키보드 선택 및 Enter 적용을 검사합니다.
- 새 검사를 Windows 소스·완성 EXE·최종 배포 위치 검사에 추가했습니다.
- 로컬 Qt 창에서 숫자 교체, 굵기 유지, 방향키 선택, Enter 적용, 되돌리기·다시 실행과 원본 PDF 보존을 확인합니다.

제보된 원본 PDF는 제공되지 않아 해당 파일 자체는 직접 검사하지 못했습니다. 글꼴 프로그램이나 명시적 스타일 정보가 없는 문서는 굵기를 확정할 수 없으며, 필요하면 편집기의 B 버튼으로 지정할 수 있습니다.

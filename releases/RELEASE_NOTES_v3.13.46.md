## 대용량 PDF 사본과 페이지 이동

- 선택한 PDF 페이지를 저장할 때 원본 전체를 페이지마다 다시 직렬화하지 않습니다.
- 사본 생성은 별도 프로세스에서 수행하며 진행 상태와 취소 버튼을 표시합니다.
- 한 PDF로 모으기와 페이지별 사본 만들기에서 선택 순서를 유지합니다.
- 생성 실패 또는 취소 시 미완성 결과를 정리하고 기존 파일을 덮어쓰지 않습니다.

## 검증 범위

- 서로 떨어진 페이지와 중복 페이지의 복사 순서, 1,722쪽 시험 문서의 이동과 되돌리기, 개별 사본, 회전 및 주석, 저장 실패와 취소를 자동 검사합니다.
- 실제 Windows 설치 파일과 마우스 드래그 동작의 검증 결과는 별도로 확인합니다.

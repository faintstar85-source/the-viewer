## 변경 내용

### PDF 편집 글꼴 목록

- 현재 편집 중인 쪽에서 사용한 글꼴을 목록 맨 위에 배치합니다. 글자를 선택하면 해당 글꼴을 먼저 보여 줍니다.
- 그 다음에는 맑은 고딕과 자주 사용하는 한글 글꼴을 배치하고, 나머지 설치 글꼴도 계속 선택할 수 있습니다.
- PDF의 `ABCDEF+MalgunGothicBold` 같은 부분 글꼴 이름과 `맑은 고딕` / `Malgun Gothic` 이름을 설치 글꼴에 연결합니다.
- 영문으로 등록된 `Malgun Gothic`은 목록에 `맑은 고딕 (Malgun Gothic)`으로 표시합니다.
- 목록 순서 변경은 현재 선택 글꼴과 문서 서식을 바꾸지 않습니다. PC에 없는 원본 글꼴은 대체 글꼴 표시 안내를 붙입니다.
- 글꼴 목록을 정리하기 위해 문서 전체 페이지를 추가로 읽지 않습니다.

### 문서·연필 편집 버튼

- 상단의 저장·인쇄 버튼 옆에 문서와 연필 모양의 **PDF 글/그림 편집** 버튼을 추가했습니다.
- 한 번 누르면 편집 모드로 들어가고, 다시 누르면 읽기 모드로 돌아갑니다.
- 편집 중에는 버튼의 배경과 테두리 색으로 켜진 상태를 표시합니다. 우클릭 메뉴의 편집 상태와도 함께 바뀝니다.
- 읽기 전용인 듀얼 오른쪽 보기와 문서가 없는 상태에서는 편집 버튼을 비활성화합니다.

### 한글·번역 버튼 기본 숨김

- 상단의 한글 변환·번역 버튼은 기본으로 숨깁니다. 기존 사용자도 별도로 표시를 선택하지 않았다면 숨긴 상태로 시작합니다.
- **정 → 번역 → 상단에 번역 버튼 표시**, **정 → 한글 변환 → 상단에 한글 변환 버튼 표시**에서 필요한 버튼만 켤 수 있습니다.
- 두 옵션은 독립적으로 저장되며, 열려 있는 도구 모음에도 바로 반영됩니다.
- 숨긴 버튼 자리는 줄여 표시합니다. 설정 탭의 실행 버튼과 기존 단축키는 계속 사용할 수 있습니다.

## 검증 범위

- 글꼴 이름 연결·문서 글꼴 우선 정렬·미설치 글꼴 처리 회귀 검사를 추가했습니다.
- 도구 모음과 글꼴 목록의 GUI 검사를 Windows 패키징 검사에 추가했습니다. 소스·완성 EXE·최종 배포 위치에서 각각 검사하며, 전체 결과는 해당 버전 GitHub Actions 기록에 남습니다.
- 로컬 Qt 화면에서 생성한 PDF 열기, 해당 PDF 글꼴 우선 표시, 편집 진입·해제, 두 설정 탭의 표시 옵션을 확인했습니다.
- 사용자 PC의 실제 대용량 문서 전체, 프린터 출력, DeepL 실서버 번역 결과를 확인했다는 의미는 아닙니다.

## 사진 탐색 수정

- 사진 한 장을 직접 열었을 때 해당 사진의 경로를 탐색 기준으로 유지합니다.
- 좌우 화살표·쪽 이동 키로 같은 폴더의 지원 사진만 파일명 숫자 순서대로 엽니다. ZIP·CBZ·PDF·텍스트·하위 폴더는 사진 이동 목록에서 제외합니다.
- 사진 위에 표시되던 이전/다음 항목 전환 패널을 숨깁니다.
- 앞뒤 사진이 없으면 현재 사진을 유지하고, 하단에 “더 이상 읽을 파일이 없습니다.”를 약 1.8초 동안 표시합니다. 닫기 버튼이 있는 오류창은 표시하지 않습니다.
- 이미 열린 여러 사진의 순서, 듀얼 비교 및 명시적으로 연 압축파일의 책 탐색은 유지합니다. 사진 자체가 손상된 경우의 읽기 오류 안내는 유지합니다.

## 검증

- 사진·ZIP·CBZ·PDF·텍스트가 섞인 폴더, 상위 폴더의 ZIP, 사진 한 장인 폴더, 대문자 확장자, 자연 정렬, 이전/다음 경계, 오래된 작업 응답을 회귀 검사합니다.
- 별도로 동봉된 PDF 작업 프로세스에도 동일한 탐색 함수를 적용하고 소스 일치 검사를 수행합니다.
- 실제 작업 프로세스의 사진 목록과 Qt의 하단 안내·자동 숨김을 Windows 소스·완성 EXE·최종 위치 검사에 추가했습니다.

- 로컬 Qt 창에서 실제 좌우 화살표, 오른쪽 방향키, 앞뒤 경계·사진 한 장 폴더, 안내 자동 숨김과 원본 파일 해시 보존을 확인했습니다. 재현: `python scripts/check_photo_navigation_ui.py` (Linux: `QT_QPA_PLATFORM=offscreen`).
